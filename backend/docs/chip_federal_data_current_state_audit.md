## Current map behavior and performance

- `frontend/src/App.jsx:278,308–311`: national start zoom 4; tract switch at zoom 10 for PLACES, ACS, SVI and FEMA (`:3389`); HPSA, CMS, USDA and funding do not use that tract branch. USDA state fallback at zoom ≤5; CDC funding has its own state/county resolver (`:3401–3427`). This is not one registry-driven state→county→tract contract.
- `frontend/src/App.jsx:6066–6154,6372–6560` requests tract or county data using a padded viewport bbox, with cached state outlines and county overlays. `backend/app/routers/tracts.py:68–111` and `county_boundaries.py:11–93` use bbox, simplification, limits and pagination. `backend/app/routers/state_geojson.py:11–96` uses a state boundary table when available, with on-demand county union fallback. General `/counties/geojson` and some legends can return national detail when unfiltered; bound all new area requests by viewport and caps. FEMA/USDA services also impose zoom-based limits.
- Geometry is reused in PostGIS tables but responses still serialize GeoJSON geometries with values, so boundaries are retransmitted across measures. React's 10-minute cache (`App.jsx:416`) and inflight dedupe (`:4175`) reduce repetition within one session; there is no verified persistent tile/cache layer. React aborts prior fetches (`:6079`) and checks latest request IDs (`:6372–6550`). Some cached stale-while-revalidate branches keep previous geometry visible; a future release-aware cache key is needed.
- Legends are source-specific (PLACES `/legend`, ACS/SVI/FEMA/USDA funding endpoints). `frontend/src/App.jsx:315,10984–10989` uses a common no-data color, while CMS has suppressed flags (`:4218,6892`); zeros can be numeric but missing/suppressed/unavailable are not consistently distinguished across datasets. PLACES county facts carry CI/footnote (`backend/app/models.py:78–101`), ACS carries MOE, CMS suppression is explicit. General map does not provide one accessible table of all displayed features; SVI has `/svi/table` and some funding chart tables.
- Current `dim_county_boundary` comes from TIGER 2023 (`backend/scripts/load_county_boundaries.py:13`), tract shapes from TIGER 2020 (`backend/scripts/download_tiger_tracts.py:5`; `import_tract_shapes.py:14`). DB holds 3,235 county, 56 state and 84,414 tract shapes. No boundary-vintage FK in general observation tables. Current PLACES county and tract vintages can differ; Food Access 2019 LRAM is specifically a 2010 tract product.

## Source questions and audit limits

1. Does the product manager want the first shared pilot to expose one carefully documented PLACES measure or all 40? The plan recommends one measure for a bounded vertical slice and metadata support for expansion.
2. Which CMS product did spreadsheet row 36 intend: linked provider enrollment, or Original Medicare utilization/GV? They have different map types and methods.
3. Which exact published state/county/tract ACS measure should prove the full hierarchy, and can an operator provide a Census API key? The Census documentation currently says a key is required.
4. Which source files are available for HPSA, CMS SSP, and ACS NMF, with original download URL and retrieval date? Repository metadata did not establish them.
5. Are there production cron jobs outside the inspected units, and what is the retention/legal policy for archived raw files? No shared policy was found.
6. Is there a valid 2010 tract boundary layer or approved crosswalk for 2019 USDA LRAM? Until then, its existing 2020-shape map join warrants review.
