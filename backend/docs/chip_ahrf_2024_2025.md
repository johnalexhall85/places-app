# AHRF 2024–2025 county selection and operations

Official [HRSA download catalog](https://data.hrsa.gov/data/download?data=AHRF#AHRF) lists the 2024–2025 county CSV and technical-documentation ZIPs. The county user guide calls this the current release. Its release label is **not** the observation year. The selected fields below are the latest documented versions of these definitions in this release: **2023**. All are published county counts, with no denominator, confidence interval, or margin of error. HRSA compiles the original publishers' data; the original sources and their restrictions remain relevant.

| Source variable and official label | CHIP label | Unit and universe | Year; original source | Geography and missing codes | Interpretation limit |
| --- | --- | --- | --- | --- | --- |
| `phys_nf_prim_care_pc_exc_rsdt_23`, “Phys,Primary Care, Patient Care” | Primary care physicians in patient care | Physicians; nonfederal, excluding hospital residents and age 75+ | 2023; AMA Physician Master File | County; blank = missing or unavailable | Physician location is not patient access or full-time equivalent. Excludes federal physicians and residents. |
| `dent_nf_fed_proflly_activ_23`, “Dentists, Total Prof Active” | Professionally active dentists | Dentists; federal and nonfederal | 2023; ADA Masterfile | County; blank = missing or unavailable | Professionally active is broader than direct patient care. Connecticut uses nine planning regions for this field. |

| `hosp_23`, “Total Number Hospitals” | Hospitals | Hospitals in the AHA survey universe | 2023; AHA Survey Database 2023 | County; blank = missing or unavailable | Survey hospital counts do not describe services or utilization. |
| `hosp_beds_23`, “Hospital Beds” | Hospital beds | Beds in total hospitals in the AHA survey universe | 2023; AHA Survey Database 2023 | County; blank = missing or unavailable | The AHRF label does not define these as staffed or available beds. |

The [county technical documentation](https://data.hrsa.gov/DataDownload/AHRF/AHRF_USER_TECH_2024-2025.zip) and crosswalk provide the field names, years, labels, universes, and contributing sources. The user guide says source data not reported are blank in AHRF since the 2013–2014 release; a zero is a reported zero. For these five fields, the downloaded CSV contains decimal integer strings, zeros, and blanks, with no observed suppression token. The adapter rejects any unexpected token. A blank retains a `missing` status and a null value; it is not assigned a numeric zero or a suppression status without publisher evidence. Source geography exclusions are stored separately as `not_published`.

The full county CSV has 3,235 unique FIPS rows. It includes eight former Connecticut counties, nine current Connecticut planning regions, discontinued Alaska `02261`, and Guam/USVI codes. The existing isolated 2024 TIGER county boundaries have 3,222 current county equivalents (including the nine Connecticut planning regions and Puerto Rico). The 13 source-only codes are never joined to newer polygons. Four selected measures have blank planning-region values; the dentist field has blank former-county values and populated planning-region values. The published map therefore shows current Connecticut planning regions as unavailable for four measures and dentist values for nine. No state or tract observations are inferred. At closer zoom, county values remain displayed.

This product uses manual full-content refresh, with automatic publication disabled. The downloaded ZIPs, extracted selected files, dictionary, metadata, timestamps, and SHA-256 checksums stay in `data/ingest/ahrf_2024_2025/`. Repeated identical source content records a duplicate run; changed content under the same release label is held for review. A newer release label or changed dictionary requires an updated registry and review before publication.

HRSA's [download page](https://data.hrsa.gov/data/download?data=AHRF#AHRF) lists “Usage limitations: None,” while the bundled county user guide contains a reproduction warning and identifies AMA, ADA, and AHA copyright restrictions. This discrepancy is retained in the source inventory for follow-up with HRSA before wider redistribution or export of raw source data. CHIP displays only the five attributed county fields.

From `backend/`:

```bash
.venv/bin/python -m alembic upgrade head
.venv/bin/python -m app.area_pilot.ahrf_cli fetch-stage-validate
.venv/bin/python -m app.area_pilot.ahrf_cli review CANDIDATE_UUID
.venv/bin/python -m app.area_pilot.ahrf_cli release-reviewed-hold CANDIDATE_UUID --semantic-sha256 REVIEWED_SEMANTIC_SHA --schema-sha256 REVIEWED_SCHEMA_SHA --metadata-sha256 REVIEWED_METADATA_SHA --operator-note 'Publisher revision reviewed against archived source'
.venv/bin/python -m app.area_pilot.ahrf_cli approve-publish CANDIDATE_UUID --semantic-sha256 REVIEWED_SEMANTIC_SHA --schema-sha256 REVIEWED_SCHEMA_SHA --metadata-sha256 REVIEWED_METADATA_SHA
.venv/bin/python -m app.area_pilot.ahrf_cli rollback RETAINED_AHRF_PUBLISHED_UUID
.venv/bin/python -m app.area_pilot.ahrf_cli deactivate
```

To add AHRF to scheduled verification, extend the existing weekly operations product list and budget its download, archive growth, disk, and run time first. The timer itself is unchanged here. Rollback changes only the AHRF active-release pointer and preserves archived candidates and published rows.
