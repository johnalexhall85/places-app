# Report Fonts

PDF report branding will use bundled fonts in this directory when available.

Preferred files:
- `Inter-Regular.ttf`
- `Inter-SemiBold.ttf`
- `Inter-Italic.ttf`

Fallback files (if Inter is unavailable):
- `SourceSans3-Regular.ttf`
- `SourceSans3-SemiBold.ttf`
- `SourceSans3-Italic.ttf`

If none of these files are present, ReportLab falls back to built-in Helvetica fonts.
